# Security

Switchboard runs on your Mac and only looks at your own local ports. It does not send what it finds anywhere. The one network call it makes is asking GitHub for the latest version, and you can turn that off in the gear menu.

## Report a problem

If you find a security problem, please don't open a public issue. Use the Report a vulnerability button on the Security tab of this repo, so only the maintainer sees it.

Say what you found, how to reproduce it and which version you used. You will get an answer within a few days.

## Which versions

Only the latest release gets fixes. Update with `brew upgrade --cask destucr/tap/switchboard` or from the gear menu.
